## Context

參見 `proposal.md`。當前頂部導航區域中的實用操作連結（存檔管理、新遊戲、主題切換）字級為 11px，且配色偏暗，導致在中央遊戲面板上方不夠醒目，使用者容易忽略。同時，畫面中殘留的藍色、橘色等雜色破壞了黑白純粹感。此外，測試與驗證繁瑣開局時缺乏自動輔助機制，因此引入可開關的「自動模式 / 開發者模式」（Auto Mode）。

## Goals / Non-Goals

**Goals:**
- 提升「存檔管理」、「新遊戲」與「開燈 / 熄燈」之視覺顯眼度與文字清晰度。
- 字級統一調整為 12px~13px，增加字距與點擊有效熱區。
- 採用符合原版極簡純文字美學之呈現方式（微標籤風格，如 `[ 存檔管理 ]`）。
- 確保在 Dark（純黑底白字）與 Light（純白底黑字）下皆具備高對比度。
- 全面掃除橘色、藍色等雜色，回歸極致純黑白單色系（Pure Monochrome）。
- 提供輕量、無副作用的 `DevAutoSystem`（自動模式），在開啟時由定時器或 Tick 驅動自動添柴、拾柴與收陷阱，方便快速測試。

**Non-Goals:**
- 不修改既有存檔 schema，自動模式狀態不寫入持久存檔（重新整理後預設為關閉，亦可選擇寫入 session）。
- 不引入重度圖示或干擾整體氛圍的彩度圖案。

## Decisions

### 1. 視覺呈現形式：微標籤文字連結風格
- **選擇**：使用 `[ 存檔管理 ]`、`[ 新遊戲 ]`、`[ 自動: 關/開 ]`、`[ 開燈 / 熄燈 ]` 之微標籤文本樣式，搭配清晰的間距與分隔線。
- **理由**：既維持《小黑屋》標誌性的純文字純黑白冷調風格，又能與正文純文字產生視覺差異，明確提示其為「可觸發之功能按鈕」。

### 2. 色彩對比度規格
- **Dark 模式**：預設採用 `#cbd5e1`（清晰亮灰白），懸停切換為 `#ffffff`（純白）並伴隨微反白，分隔線採 `#64748b`。
- **Light 模式**：預設採用 `#334155`（清晰深藍灰/黑），懸停切換為 `#000000`（純黑），分隔線採 `#94a3b8`。

### 3. 純黑白單色系收斂（Pure Monochrome Harmonization）
- **選擇**：全面將日誌訊息（story, event, warn, info）、房間火堆狀態文字、彈窗標題與框線全數收斂為純白（Dark）或純黑（Light）。
- **理由**：忠實呈現《小黑屋》標誌性的黑白印刷文字冒險質感，杜絕現代彩色 RPG 的雜亂感。事件時間遠近僅由漸層透明度（Alpha 1.0 -> 0.75 -> 0.5 -> 0.25）展現。

### 4. 自動模式架構（`DevAutoSystem`）
- **系統職責**：
  - 透過 `enabled: boolean` 控制啟動與停止。
  - 在每個週期（例如每 500ms 或每次 Tick）：
    1. **檢查火勢**：若火勢小於 `burning`（如 `dead` 或 `flickering`），且房間添柴按鈕冷卻時間小於等於 0，呼叫 `roomSystem.lightFire()` 或 `roomSystem.stokeFire()`。
    2. **檢查拾柴**：若外圍森林已解鎖（`gameState.isOutsideUnlocked`）且拾柴冷卻已就緒，觸發拾柴動作。
    3. **檢查陷阱**：若有已建造之陷阱且捕獲資源就緒，自動觸發檢查陷阱動作。
  - 完全重用既有業務系統，不破壞遊戲狀態不變量（invariants）。

## Risks / Trade-offs

- [頂部項目增加可能擠壓空間] → 在 800px ~ 1020px 區域內精算各項目的寬度與間距，文字簡潔（`[ 自動: 關 ]` 約 60px），佈局寬裕不折行。
- [自動模式可能與手動操作衝突] → 自動模式僅在冷卻完畢時呼叫現有 API，若玩家手動點擊不會產生狀態異常或重複扣除。
