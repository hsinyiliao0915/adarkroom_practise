## Why

目前遊戲頂部右側的「存檔管理」與「新遊戲」以及主題切換文字過於灰暗、字級偏小，且畫面混雜了橘色（#f6ad55）與藍色（#60a5fa、#38bdf8）等多餘雜色，破壞了《小黑屋》標誌性的黑白純粹極簡氛圍。此外，在開發與手動測試過程中，頻繁手動點擊添柴、拾柴與檢查陷阱耗費大量時間，因此需要提供「自動模式 / 開發者模式」（Auto Mode）開關，便於高速推進進度與驗證遊戲循環。

## What Changes

- **全面回歸純粹黑白單色美學（Pure Monochrome）**：全面移除日誌、房間狀態與彈窗中的橘色與藍色彩色文字，所有訊息均採用純白（Dark 模式）或純黑（Light 模式），僅藉由透明度漸層（Alpha 1.0 -> 0.75 -> 0.5 -> 0.25）體現時間流逝。
- **強化頂部工具列醒目度與可讀性**：將「存檔管理」、「新遊戲」及「開燈 / 熄燈」採用 `[ 存檔管理 ]`、`[ 新遊戲 ]`、`[ 開燈 / 熄燈 ]` 微線框文字樣式，字級提升至 12px~13px，建立明確的點擊標的與即時懸停反白回饋。
- **新增「開發者 / 自動模式」開關（Auto Mode）**：在頂部工具列加入 `[ 自動: 關 ]` / `[ 自動: 開 ]` 切換按鈕。開啟後系統在背後自動依照冷卻定時執行點火/添柴、拾柴與收陷阱，解放雙手加速驗證。
- **完整支援 Dark / Light 雙版本**：外圍純灰，中央純黑白，色彩乾淨無任何雜色干擾。

## Capabilities

### New Capabilities
- `header-utility-navigation`: 規範頂部右側實用功能導航之視覺階層、點擊醒目度與雙主題純黑白單色美學標準。
- `developer-auto-mode`: 規範開發者/自動模式的開關切換、基礎動作自動執行（添柴、拾柴、收陷阱）與單色視覺呈現。

### Modified Capabilities
（無修改現有能力需求）

## Impact

- 影響元件：`src/scenes/MainScene.ts`（頂部導航區域、自動模式整合）、`src/systems/DevAutoSystem.ts`（新自動輔助系統）、`src/ui/LogPanel.ts`（純黑白日誌）、`src/ui/RoomView.ts`（純黑白狀態文字）、`src/ui/SaveLoadModal.ts`（純黑白彈窗）、`src/config/ThemeManager.ts`（單色調色盤）。
- 無破壞性變更，不影響正式存檔格式。
